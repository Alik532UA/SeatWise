# ADR 0001: Застосування афінної площини над полем Галуа GF(8) та евристичного пошуку

## Статус
Прийнято

## Контекст
У задачах організації ділових зустрічей (Networking / Speed Dating / Social Golfer Problem) головна мета — мінімізувати або усунути повторні зустрічі учасників за столами.
Для конфігурації $N = 64$ (8 столів по 8 місць) наївні жадібні алгоритми часто потрапляють у локальні оптимуми вже після 4-5 раундів, генеруючи колізії.

## Рішення
1. Для конфігурації 64 особи використовувати теоретико-груповий підхід: афінну площину порядку 8 над кінцевим полем $GF(2^3) = GF(8)$.
   - Поле генерується за незвідним многочленом $x^3 + x + 1 = 0$.
   - Точки площини відповідають 64 учасникам.
   - Прямі площини відповідають столам у раундах.
   - Паралельні класи прямих утворюють рівно 9 раундів, де будь-які дві прямі одного класу не перетинаються, а прямі різних класів перетинаються рівно в одній точці. Це дає строге математичне доведення відсутності повторних зустрічей (0 колізій).
2. Для довільних конфігурацій $(N, T, C)$ застосовувати стохастичний жадібний пошук з матрицею суміжності.

## Наслідки
- Гарантовані 9 ідеальних раундів для стандарту 64 учасників.
- Миттєвий час генерації (< 10мс).

# ADR 0002: Модульна архітектура скінів (Skins) та реактивність на базі Svelte 5 Runes

## Статус

Прийнято

## Контекст

Різні категорії користувачів мають різні потреби:

- Модераторам івенту потрібен табличний звіт з можливістю копіювання/друку;
- Учасникам на смартфонах потрібен компактний інтерфейс без горизонтального скролу;
- Ведучим на великих екранах потрібна естетична візуалізація круглих столів.

## Рішення

1. Розділити інтерфейс на три взаємозамінні компоненти-скіни (`ProfessionalSkin`, `CompactSkin`, `VisualSkin`).
2. Уся бізнес-логіка та реактивний стан виносяться у класи-контролери з використанням Svelte 5 Runes (`$state`, `$derived`):
   - `SeatingController.svelte.ts`
   - `UIController.svelte.ts`
   - `ThemeController.svelte.ts`
3. Контролери передаються через Svelte Context API (`setContext` / `getContext`) у кореневому макеті.
4. Доступ до браузерного сховища суворо ізольований через фасад `$lib/services/storage.ts` з префіксом `seatwise_`.

## Наслідки

- Повна незалежність візуального представлення від алгоритмічного ядра.
- Просте додавання нових скінів або адаптацій без ризику регресій у розрахунках.

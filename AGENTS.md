# AGENTS.md — SeatWise

> **Спершу прочитай [PROJECT-CONTEXT.md](PROJECT-CONTEXT.md).** Там зафіксовано архітектурні інваріанти за каноном v10: параметри адресації, префікси сховища `seatwise_`, математичні алгоритми полів Галуа $GF(8)$, політика безпеки (CSP) та стандарти якості. Цей файл — практична витримка для щоденної роботи AI-агентів.

---

## 1. Головні правила та архітектурні інваріанти

1. **Реактивність Svelte 5 Runes**:
   - Жодних старих Svelte 4 stores (`writable`, `readable`) чи реактивних декларацій `$:`.
   - Використовувати виключно Runes: `$state`, `$derived`, `$effect`, `$props`.
   - Стан бізнес-логіки інкапсулюється у класи-контролери з розширенням `.svelte.ts` у папці `src/lib/controllers/`.

2. **Ізоляція Web Storage**:
   - **СУВОРО ЗАБОРОНЕНО** викликати `localStorage` чи `sessionStorage` напряму в компонентах або контролерах.
   - Використовувати виключно фасад `$lib/services/storage.ts`.
   - Усі ключі автоматично мають префікс `seatwise_`.

3. **Математична логіка (Social Golfer)**:
   - Файл `src/lib/algorithms/seating.ts` містить чисті функції. Не вносити змішування логіки інтерфейсу та математичних обчислень.
   - Для 64 учасників (8 столів по 8 місць) застосовується афінна площина поля Галуа $GF(8)$. Зміна цього коду вимагає валідації через `seating.test.ts`.

4. **Безпека та CSP**:
   - Жодного сирого `{@html}` без санітизації.
   - Усі інлайн-скрипти в `app.html` автоматично хешуються під час збірки.

5. **Мова та кодування**:
   - Основна мова документації та комунікації — **українська**.
   - Усі markdown файли зберігати в UTF-8.
